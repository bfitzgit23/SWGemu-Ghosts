
# SWGemu Ghosts - Aftermath Server

Custom SWGEmu server with merged content from AOTC, Bloodfin, and other community servers.

## Features

- Custom species support (Kel Dor, Gungan, etc.)

- Merged hair/appearance systems

- Custom content from multiple server sources

## Setup

1. Install dependencies (see SWGEmu wiki)

2. Copy MMOCoreORB/bin/conf/config.lua.template to config.lua

3. Edit config.lua with your database credentials

4. Place your TRE files in the path specified in config

5. Build and run
